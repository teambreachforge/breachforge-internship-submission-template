# Task 01 — Cybersecurity Concept Identification

## Scenario 1

### Scenario

A company stores customer information on a database server. The server
is running outdated software with a known security weakness.

### Answer

**Asset:** Database server and customer information

**Threat:** Attacker

**Vulnerability:** Outdated software with a known security weakness

**Possible CIA Impact:** Confidentiality, Integrity, or Availability

### Why?

The database and customer information are valuable assets. The outdated
software is a weakness that could be exploited. An attacker could
potentially access or modify the information or disrupt the server.

## Scenario 2

### Scenario

An employee receives an email asking them to enter their company password
on a suspicious website.

### Answer

**Asset:** Employee account / company credentials

**Threat:** Attacker attempting to obtain the credentials

**Vulnerability:** User may enter credentials into the suspicious website

**Possible CIA Impact:** Confidentiality

### Why?

The employee's account and credentials are valuable to the organization.
An attacker may try to obtain the credentials through the suspicious
website and use them to gain unauthorized access.


---

## Scenario 3

### Scenario

An attacker gains unauthorized access to a company's database and changes
customer information.

### Answer

**Asset:** Customer database and customer information

**Threat:** Attacker

**Vulnerability:** Not enough information is provided to identify the
specific vulnerability

**CIA Property Affected:** Integrity

### Why?

The attacker has changed customer information without authorization.
Because the information has been modified, its integrity has been
affected.

# Short Answers

## 1. What do we call something valuable that needs protection?

Asset

## 2. What do we call a weakness that could be exploited?

Vulnerability

## 3. What do we call something that could potentially cause harm?

Threat

## 4. Which CIA property protects information from unauthorized access?

Confidentiality

## 5. Which CIA property protects information from unauthorized changes?

Integrity

## 6. Which CIA property ensures systems and information remain accessible?

Availability

# What I Learned

Cybersecurity is about protecting systems, networks, accounts, and data.
I learned that an asset is something valuable that needs protection.

I also learned the difference between a threat and a vulnerability. A
threat can potentially cause harm, while a vulnerability is a weakness
that could be exploited.

The CIA Triad helped me understand the main security goals:
Confidentiality protects information from unauthorized access, Integrity
protects information from unauthorized changes, and Availability ensures
that systems and information can be accessed when needed.
