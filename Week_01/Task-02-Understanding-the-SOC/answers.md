## Part 2 — L1 SOC Analyst

Example answer:

An L1 SOC Analyst monitors security activity, performs initial
investigation, documents findings, and escalates issues when necessary.


## Part 3 — Short Scenario

Example:

20 failed login attempts within a short period may require attention
because the activity could be unusual.

An analyst could check the source of the attempts, the user account,
and whether a successful login happened afterward.

The activity should be investigated before deciding whether it is an
actual attack.


## Revision Notes

Example notes:

- A SOC monitors an organization's security activity.
- L1 analysts perform initial investigation.
- Unusual activity should be investigated before reaching a conclusion.
