# BreachForge Labs Internship Submission Template

This repository is a sample template for organizing internship tasks
and submissions.

It is provided to help interns understand:

- How to organize tasks on GitHub
- How to name folders and files
- How to format answers using Markdown
- How to maintain a clean internship portfolio
