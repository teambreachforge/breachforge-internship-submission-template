This repository is a sample template for organizing your internship
tasks and submissions.

It helps you understand:

• How to organize your internship work on GitHub
• How to create folders and files
• How to format your answers using Markdown
• How to keep your work organized throughout the internship


IMPORTANT

You only need ONE GitHub repository for your entire internship.

Do not create a new repository for every task.

Your repository will contain all your weekly tasks.


RECOMMENDED STRUCTURE

Your-Internship-Repository/
│
├── Week_01/
│   ├── Task-01-Cybersecurity-Fundamentals/
│   │   └── answers.md
│   │
│   └── Task-02-Understanding-the-SOC/
│       └── answers.md
│
├── Week_02/
│   ├── Task-01/
│   │   └── answers.md
│   │
│   └── Task-02/
│       └── answers.md
│
└── Week_03/
    └── ...


SIMPLE GITHUB GUIDE

1. OPEN YOUR REPOSITORY

Open your GitHub internship repository.


2. CLICK "ADD FILE"

Select:

Add file → Create new file


3. CREATE THE FOLDER AND FILE

In the filename box, type the complete path.

Example:

Week_01/Task-01-Cybersecurity-Fundamentals/answers.md

GitHub will automatically create the folders and the answers.md file.


4. ADD YOUR ANSWERS

Write your task answers inside answers.md.


5. SAVE YOUR WORK

Scroll down and click:

Commit changes

Your work is now saved to your GitHub repository.


CREATING THE NEXT TASK

For Day 2, create:

Week_01/Task-02-Understanding-the-SOC/answers.md

For a new week, create:

Week_02/Task-01-Task-Name/answers.md

Continue using the same repository throughout your internship.


SAMPLE FILES

This repository contains sample files to show how your submissions
should be organized and formatted.

The sample content is only for reference.

Do not copy the sample answers into your internship submission.


LEARNING INTEGRITY

Write your internship task answers in your own words.

Do not use AI to generate or rewrite your task submissions.

If you have a doubt about a concept or task, ask the
BreachForge Labs mentor directly.


SUBMISSION

After completing a task, submit the GitHub link requested in the
Google Form provided with that task.
