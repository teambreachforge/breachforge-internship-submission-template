# BreachForge Labs Internship Submission Template

This repository is a sample template for organizing your internship tasks and submissions.

It will help you understand:

* How to organize your internship work on GitHub
* How to create folders and files
* How to format answers using Markdown
* How to keep your work organized throughout the internship

---

## Important

You only need **one GitHub repository for your entire internship**.

You do not need to create a new repository for every task.

All your weekly tasks and submissions should be maintained inside the same repository.

---

│   │

│   │
│   ├── Task-01/

The exact week, task, and folder names may be different depending on your internship track.

## How to Create a Folder and File

You do not need to create folders separately.

GitHub can create the folders and file together when you create a new file.

### Step 1 — Open Your Repository

Open your GitHub internship repository.

### Step 2 — Click "Add file"

Click:

```text
Add file → Create new file
```

### Step 3 — Enter the Folder and File Name

In the filename box, type the complete path.

Example:

```text
Week_01/Task-01-Cybersecurity-Fundamentals/answers.md
```

The `/` tells GitHub to create folders.

GitHub will automatically create:

```text
Week_01/
└── Task-01-Cybersecurity-Fundamentals/
    └── answers.md
```

### Step 4 — Write Your Answers

Write your task answers inside:

```text
answers.md
```

Follow the instructions provided in the task file.

### Step 5 — Save Your Work

Scroll down and click:

```text
Commit changes
```

Your folder and file will now be saved in your repository.

---

## Creating the Next Task

For the next task, continue using the same repository.

For example:

```text
Week_01/Task-02-Understanding-the-SOC/answers.md
```

GitHub will create:

```text
Week_01/
├── Task-01-Cybersecurity-Fundamentals/
│   └── answers.md
│
└── Task-02-Understanding-the-SOC/
    └── answers.md
```

For a new week, create the folder and file using the same method:

```text
Week_02/Task-01-Task-Name/answers.md
```

Continue using the same repository throughout your internship.

---

## How to Edit an Existing File

If you have already created an `answers.md` file:

1. Open your repository.
2. Open the required `Week` folder.
3. Open the required `Task` folder.
4. Open `answers.md`.
5. Click the pencil/edit icon.
6. Update your answers.
7. Click **Commit changes**.

## Submission

After completing a task, submit the GitHub link requested in the Google Form provided with that task.

Before submitting, make sure:

* Your answers are complete.
* Your file is in the correct folder.
* Your latest changes are committed to GitHub.
* You are sharing the correct GitHub link.
* The submitted repository contains your latest work.
